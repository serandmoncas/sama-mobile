# Mapa Base con MapLibre (E3-01) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "Mapa" tab's placeholder with a real MapLibre map centered on Antioquia, using free OpenFreeMap tiles, with a "Mi ubicación" button that requests location permission and shows the user's position when granted.

**Architecture:** `@maplibre/maplibre-react-native` renders the map via `Map`/`Camera`/`UserLocation` components. `app/(tabs)/mapa.tsx` wraps the map in a themed container with the existing header pattern (title + `accessibilityRole="header"`, matching all other screens since E1-05), and a floating location button on top of the map. Location permission is requested explicitly via `expo-location` when the button is pressed — MapLibre itself never prompts on its own in this flow, since `<UserLocation />` only mounts after permission is confirmed granted.

**Tech Stack:** Same as prior plans (Expo Router, TypeScript strict, Jest + `jest-expo`, `@testing-library/react-native`), plus `@maplibre/maplibre-react-native` (native module) and `expo-location`.

## Global Constraints

- Branch `mapa-base`, branched from `main`.
- New dependencies explicitly allowed for this cycle: `@maplibre/maplibre-react-native` and `expo-location`, with their config plugins in `app.json`.
- No tile source requiring an API key or paid account — use OpenFreeMap only.
- UI copy in Spanish; code identifiers in English. TypeScript strict; no `any`.
- Do not modify `app/_layout.tsx`, `app/alerta/[id].tsx`, or any screen other than `app/(tabs)/mapa.tsx`.
- Do not modify `constants/Colors.ts` or `constants/AlertColors.ts`.
- Do not add the location permission to the onboarding flow — it's requested contextually from the map screen's button, never elsewhere.
- Keep accessibility conventions from E1-05 (`accessibilityRole`, `accessibilityLabel`, `minHeight`/44px touch target) on the location button and the screen's title.
- **This ticket adds the project's first native dependency requiring a custom dev build.** `app/(tabs)/mapa.tsx` can no longer be previewed in Expo Go (confirmed: Expo Go throws `TurboModuleRegistry.getEnforcing(...): 'MLRNCameraModule' could not be found` — hand-verified in this exact repo). Every other screen keeps working in Expo Go unchanged. Verifying this screen requires `npx expo run:ios` (or `run:android`), which was already exercised successfully in this environment on both the iOS Simulator and a physical iPhone earlier in this project.
- **Gotcha hand-verified in this exact repo:** an emoji character (`📍`) used as a button label rendered as a literal "?" glyph on-device in this build's font stack. Use `@expo/vector-icons`'s `FontAwesome` instead (already a project dependency, already used for the tab bar icons in `app/(tabs)/_layout.tsx`) — confirmed to render correctly.
- **Gotcha hand-verified in this exact repo:** after `fireEvent.press` on a `Pressable` whose `onPress` handler is `async` and calls `setState` after an `await`, asserting immediately causes a React `act()` warning even when wrapped in `waitFor` for an unrelated assertion. Wrap the `fireEvent.press` call itself in `await act(async () => { fireEvent.press(...) })` to keep the whole async state transition inside one `act` boundary and get pristine test output.
- **Known limitation, explicitly out of scope:** the backlog's original acceptance criterion "rendimiento fluido en gama baja (probado en dispositivo Android de referencia ≤2GB RAM)" cannot be verified in this environment — no such device is available. Verification in this plan is functional only (compiles, runs, doesn't crash on the devices actually available), not a performance benchmark.
- Every verification step must actually be run and its real output checked — never mark a step done because it "should" pass.

- [ ] **Step 3: Replace the screen**

Replace the entire contents of `app/(tabs)/mapa.tsx`:

```tsx
import { useState } from 'react';
import { Pressable, StyleSheet } from 'react-native';
import FontAwesome from '@expo/vector-icons/FontAwesome';
import * as Location from 'expo-location';
import { Camera, Map, UserLocation } from '@maplibre/maplibre-react-native';
import { Text, View } from '@/components/Themed';
import { useColorScheme } from '@/components/useColorScheme';
import Colors from '@/constants/Colors';
import Spacing from '@/constants/Spacing';
import Typography from '@/constants/Typography';

const MAP_STYLE = 'https://tiles.openfreemap.org/styles/liberty';
const ANTIOQUIA_CENTER: [number, number] = [-75.5, 6.9];
const ANTIOQUIA_ZOOM = 7;

export default function MapaScreen() {
  const [locationGranted, setLocationGranted] = useState(false);
  const theme = useColorScheme();
  const colors = Colors[theme];

  async function handleLocationPress() {
    const { status } = await Location.requestForegroundPermissionsAsync();
    setLocationGranted(status === 'granted');
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title} accessibilityRole="header">
        Mapa de estaciones
      </Text>
      <View style={styles.mapContainer}>
        <Map style={styles.map} mapStyle={MAP_STYLE}>
          <Camera
            initialViewState={{
              center: ANTIOQUIA_CENTER,
              zoom: ANTIOQUIA_ZOOM,
            }}
            trackUserLocation={locationGranted ? 'default' : undefined}
          />
          {locationGranted && <UserLocation />}
        </Map>
        <Pressable
          testID="boton-mi-ubicacion"
          onPress={handleLocationPress}
          accessibilityRole="button"
          accessibilityLabel="Mi ubicación"
          style={[
            styles.locationButton,
            { backgroundColor: colors.background, borderColor: colors.border },
          ]}
        >
          <FontAwesome name="location-arrow" size={20} color={colors.tint} />
        </Pressable>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
  },
  title: {
    ...Typography.title,
    textAlign: 'center',
    padding: Spacing.lg,
  },
  mapContainer: {
    flex: 1,
  },
  map: {
    flex: 1,
  },
  locationButton: {
    position: 'absolute',
    bottom: Spacing.xl,
    right: Spacing.xl,
    width: 44,
    height: 44,
    borderRadius: 22,
    borderWidth: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```
